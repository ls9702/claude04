## Mac 세션이 할 일 (빌드 체크포인트 R1-S4 — 실기기 첫 설치)
1. `git pull` → `scripts/build.sh` → 컴파일 오류는 `docs/REVIEW_LOG.md` R1-S4 "컴파일 확신이 낮은 지점"부터 → 고쳐 `fix(R1-S4): …` 커밋
2. `scripts/test.sh` (76개 예상)
3. `docs/MAC_SETUP.md` §4 (개발자 모드·무료 서명·신뢰) → `scripts/install-device.sh`
4. iPhone 12 Pro에서 측정·확인 (결과는 BUILD_LOG):
   - 촬영 탭 상단 DEBUG 통계 `Nfps · 버림 a+b · Npx`: 자동/흑백/음식(선명도 높음) 프리셋별 fps. 콘솔 "프리뷰 프레임 크기 WxH"
   - 프리뷰 **방향**(뒤집힘·회전 여부), 색·채도(사진 앱 원본과 비교)
   - 탭 포커스가 탭 위치와 맞는지(모서리 4곳), 핀치 줌 1~10×
   - 촬영 → 배지 → 사진 앱에서 "편집됨"·되돌리기·위치·날짜, 보정본이 프리뷰와 같아 보이는지, 가로로 든 사진이 가로로 나오는지
   - 연속 5장 촬영: 셔터 막힘 없음, 배지 감소, 장당 후처리 시간
   - 10분 연속 프리뷰 후 발열 아이콘·해상도 전환
   - 백그라운드 ↔ 복귀, 탭 전환 후 프리뷰 재개
   - 보정 탭: 10장 일괄 저장 시간, 프리셋 전환 지연
5. 이 파일의 "진행 중"·"단계 상태" 갱신. 튜닝 값 변경(baseDimension, autoRefreshInterval, sessionPreset)은 직접 커밋해도 됨
