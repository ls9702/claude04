## Mac 세션이 할 일 (릴리즈 1 빌드 체크포인트)
1. `git pull` → `scripts/build.sh` → 오류는 REVIEW_LOG "릴리즈 1 전체 리뷰" 컴파일 의심 8지점 → S8a·S8b·S8c 로그 순으로 → `fix(R1-S8c): …`
2. `scripts/test.sh` (약 190개 예상)
3. `scripts/install-device.sh` → iPhone 12 Pro **낮**:
   - 콘솔: "활성 포맷 1920x1440 … 사진 4032x3024", "프리뷰 프레임 크기 1440x1920", "촬영 사진 크기 4032x3024", "전환 계수 [2.0, 4.0]"
   - DEBUG 통계 fps(기대 28~30, 버림 0~2), 10분 후 열 상태·발열, 저전력 모드 켜면 24fps·배너
   - 렌즈 0.5×/1×/2×·시작 1×·핀치, 전면(프리뷰 미러·저장 비반전·탭 노출·가로 셀피·얼굴 마커 좌우·인물 모드 제안 1회)
   - 인물: 셔터 옆 노란 버튼, 강도 칩 3단계(촬영↔앨범 동기), 길게 눌러 원본, 앨범 기본/인물 패널·얼굴 확대, 피부톤 50·100, 윤곽 배경 휨, 배경 흐림 50·100(경계·방향·사람 없는 사진 무변화·저장 시간)
   - 썸네일→사진 앱, 보정 탭 닫기, 10장 일괄 저장 시간과 실패 사유 표시
   - 설정: 프레임 레이트 24/30, 백업 내보내기(공유 시트)·가져오기(병합/교체), 정보(모델 있음·커널·서명 만료일), 데이터 초기화(사진 무영향)
4. **밤**: 야경 프리셋 저장 3초 이내·품질·"저조도 경로: 모델", 어두운 프리뷰 밝기(프레임 간격 수정 후), 20분 연속 촬영(멈춤 감시·발열 배너), 전화 수신 시 세션 중단·복귀
5. 튜닝 값은 직접 커밋 가능. 통과 시 BUILD_LOG에 "릴리즈 1 완료" 기록, 이 파일 단계 상태 갱신
