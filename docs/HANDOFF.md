## Mac 세션이 처음 할 일
1. `docs/MAC_SETUP.md` §1~§3 (환경 준비, 저장소, `xcodegen generate`)
2. `scripts/build.sh` → 결과를 `docs/BUILD_LOG.md`에 기록
3. 컴파일 오류는 최소 수정으로 고쳐 `fix(R1-S0): …` 커밋·푸시 (설계 변경 금지)
4. `scripts/install-device.sh` → iPhone에서 4개 탭·카메라 프리뷰·사진 저장 확인 → BUILD_LOG에 관찰 기록
