## Mac 세션이 처음 할 일
1. `docs/MAC_SETUP.md` §1~§3 (환경 준비, 저장소, `xcodegen generate`)
2. `scripts/build.sh` 실행 → 결과를 `docs/BUILD_LOG.md`에 기록
3. 컴파일 오류가 있으면 최소 수정으로 고쳐 커밋·푸시 (설계 변경은 하지 않음)
4. `scripts/install-device.sh`로 iPhone 설치 → 4개 탭·카메라·사진 저장 확인 → BUILD_LOG에 관찰 기록
5. 이 파일의 "진행 중"·"단계 상태" 갱신
