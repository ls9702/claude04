## Mac 세션이 처음 할 일 (빌드 체크포인트 R1-S3)
1. `docs/MAC_SETUP.md` §1~§3 (환경 준비, 저장소, `xcodegen generate`)
2. `scripts/build.sh` → 컴파일 오류는 `docs/REVIEW_LOG.md` 각 단계의 "컴파일 확신이 낮은 지점"부터 확인 → 고쳐 `fix(R1-Sn): …` 커밋·푸시. 설계 변경은 아래 "논의 필요"에
3. `scripts/test.sh` → 실패 테스트 기록(특히 `testBundledMonoLUTLoads`: .cube 번들 포함 여부)
4. `scripts/install-device.sh` → iPhone에서 확인할 것:
   - 촬영 탭: 프리뷰, 탭 포커스, 촬영 → 사진 앱에 저장, 사진 정보에 **위치·날짜** 표시(위치 권한 허용 시)
   - 보정 탭: 사진 여러 장 선택 → 프리셋/슬라이더 반응 속도 → 길게 눌러 전/후 → "이 사진 저장(비파괴)" → 사진 앱에서 "편집됨"·**되돌리기** 동작·위치·날짜 유지 → "사본으로 저장" → 새 사진에 날짜·위치 있음 → 10장 일괄 저장·취소
   - 설정 탭: 프리셋 6종·템플릿 3종·규격 4종 표시
5. 관찰·측정(일괄 10장 소요 시간, 프리셋 전환 지연)을 `docs/BUILD_LOG.md`에 기록, 이 파일의 "진행 중"·"단계 상태" 갱신
